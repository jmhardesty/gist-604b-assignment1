## Understanding Git Workflow
Explain in 2–3 sentences the difference between:
- Local workspace (Codespace)
- Remote repository (GitHub.com)
A local workspace (like Codespace) is where you write code and those changes remain local until you push them to a remote repository. A remote repository stores code in a centralized location and allows for collaboration and community input.
